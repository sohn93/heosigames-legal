Formula: When a normal stage monster is defeated, the game first checks whether a collection item drops. If it drops, rarity is selected by the weights below, then one non-maxed item of that rarity is selected uniformly from the melee weapon, ranged weapon, helmet, armor, glove, and earring collection candidates.

Note: Auto-unlocked collection entries are not included in this random drop table. Collection item names are not defined in the project data, so items are listed by collection type and index.
